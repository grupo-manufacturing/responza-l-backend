# Responza Backend

Node.js API for waitlist, public blogs, and admin.

## Local

```bash
cp .env.example .env
npm install
npm run dev
```

## Render

- **Root directory:** `backend` (if the repo contains both frontend and backend)
- **Build command:** `npm install && npm run build`
- **Start command:** `npm start`

TypeScript and `@types/*` are regular dependencies so `tsc` works when Render installs with `NODE_ENV=production`.

Set env vars from `.env.example`.
